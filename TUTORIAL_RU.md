# Legacy Host — подробная инструкция (RU)

Пошаговый разбор: что нажимать в приложении и что отвечать, когда юзербот просит данные.

## 0. Что подготовить заранее

1. **Аккаунт Telegram** — тот, на котором будет работать юзербот.
2. **Инлайн-бот** — отдельный бот, оканчивающийся на `bot` (например `@my_cool_bot`).
   Создается за минуту в [@BotFather](https://t.me/BotFather): команда `/newbot` → имя → юзернейм.
   Токен от BotFather НЕ нужен — приложению достаточно юзернейма.
3. **API ID и API HASH** — берутся один раз на https://my.telegram.org/apps
   (вход по номеру телефона → раздел App configuration → `api_id` это цифры, `api_hash` это строка).
   Понадобятся только при самой первой установке.
4. Заряженный телефон и Wi-Fi: установка Linux и пакетов качает сотни мегабайт.
   Когда приложение попросит отключить оптимизацию батареи — разреши, иначе Android убьет долгую установку.

## 1. Кнопки по порядку

| Шаг | Кнопка | Что происходит |
|-----|--------|----------------|
| 1 | `INSTALL LINUX` | Скачивает и распаковывает Ubuntu в телефон. Долго (5–20 минут). Ничего не трогай, смотри лог. |
| 2 | `INSTALL LEGACY` / `UPDATE TO LEGACY` | Клонирует юзербота в `/root/Legacy`, создает виртуальное окружение, ставит пакеты. Если раньше стоял Ratko/Heroku — данные (сессии, база) переедут автоматически. |
| 3 | `START BOT` | Запускает юзербота. Перед первым запуском спросит юзернейм инлайн-бота. |

Остальные кнопки: `UPDATE LEGACY` — обновить код юзербота; `REAPPLY PATCHES` — переустановить патчи; `STOP PROCESS` — остановить; `COPY LOGS` — скопировать лог.

## 2. Что отвечать боту — разбор каждого вопроса

### «inline bot username, e.g. my_cool_bot» (спрашивает приложение)

Отвечай: **юзернейм твоего инлайн-бота из пункта 0**, например:

```
my_cool_bot
```

Без `@`, маленькими буквами, обязательно оканчивается на `bot`. Создать можно в @BotFather командой `/newbot`.

### «Enter API ID» / «Enter API HASH» (первый запуск)

Отвечай цифрами с my.telegram.org:

```
12345678
```

затем строкой-хешем:

```
abcdef1234567890abcdef1234567890
```

Спрашивается один раз, сохраняется в конфиг.

### «Use QR code? [y/N]»

Выбор способа входа:

- Ответ `y` — в логе появится QR-код. Наведи на него камеру **другого** устройства, где открыт Telegram → подтверди вход там.
- Ответ `N` (или просто Enter) — классический вход по номеру телефона, см. ниже.

### «Enter phone:»

Твой номер в международном формате, например:

```
+79161234567
```

или

```
+380971234567
```

Плюс в начале обязателен.

### Код из Telegram

После номера в твой Telegram (в официальное приложение, в чат **Telegram**) придет сообщение с кодом из 5 цифр. Введи его в терминал приложения:

```
48392
```

Код живет несколько минут. Если протух — перезапусти бота (`STOP PROCESS` → `START BOT`) и начни заново.

### «Enter 2FA password» / пароль двухэтапной аутентификации

Если в Telegram включена двухэтапная аутентификация (Настройки → Конфиденциальность → Двухэтапная аутентификация), введи **именно ее пароль** (не код из SMS!):

```
мойСекретныйПароль123
```

Если двухэтапки нет — этот вопрос не появится.

### «session name» / «terminal name» (меню приложения)

Это НЕ данные Telegram, а имена профилей внутри хоста:

- `session name` — профиль аккаунта (`main` — основной; для второго аккаунта придумай имя латиницей, например `second`).
- `terminal name` — именованная вкладка терминала, любое имя латиницей.

## 3. Типичные ошибки

- **«Invalid phone number»** — забыл `+` в начале или опечатка в цифрах.
- **«Code expired / Invalid code»** — код протух или введен с ошибкой. Начни вход заново.
- **«FloodWait»** — слишком много попыток за короткое время. Подожди указанное число секунд/минут и повтори.
- **Бот просит API ID по кругу** — неверно введен `api_hash` (проверь, что скопирован целиком, без пробелов).
- **После `.update` / `.restart` приложение закрывается** — исправлено в актуальной версии APK, обнови приложение.
- **Клавиатура закрывает поле ввода** — исправлено: поле само поднимается над клавиатурой.

## 4. Обновления

- Юзербот: команда `.update` прямо в Telegram (бот сам скажет, когда выйдет обнова).
- Приложение: раздел Releases в репозитории `legacy-apk`, ставится поверх, данные сохраняются.
